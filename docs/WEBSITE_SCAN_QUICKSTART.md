# 网站一键体检：最简使用说明

这个入口适合第一次使用 WhaleGuard 的人。你不需要先手工创建 Project、Scope、Finding、Evidence 或 Report；向导会在权限允许时安全完成这些关联工作。

## 三步完成第一次体检

1. 启动 WhaleGuard，访问 <http://127.0.0.1:3000> 并登录。
2. 打开 **网站体检**，填写你拥有或已明确授权的精确网址。
3. 确认“安全只读”授权；AI 是第三步中的可选增强，可以直接选择“暂不使用 AI”并开始检查。

如果没有指定项目，平台会复用或创建当前用户的 **我的网站体检** 隔离项目，再为本次目标创建或续期一条 24 小时的精确 URL Scope。自动创建项目需要 `projects.write`，发起体检需要 `runs.execute` 与 `scopes.write`；默认管理员和安全工程师角色具备这些权限。

规则体检不需要 API Key、模型下载或 GPU。若之后接入真实 AI，API Key 只在浏览器内存中停留到本次提交完成，后端使用项目加密密钥加密保存，列表接口只返回掩码。密钥只会发往你配置的模型 API，不会发送给被检查的网站。

## 为什么本地平台可以使用远程 AI 检查本地网站

远程模型通常不能直接访问你电脑里的 `localhost`。WhaleGuard 采用两段式流程：

1. WhaleGuard API 在本机或 Docker 私有网络中，对目标做一次有大小限制的只读请求，并用确定性规则检查 HTTPS、安全响应头、Cookie 属性、表单传输、混合内容和版本暴露。
2. 平台只把脱敏后的检查项、规则分数和修复提示发给你选择的模型，让模型做中文解释和修复优先级排序。

响应正文、Cookie 值、登录凭据和 API Key 都不会进入模型分析上下文。规则分数是原始依据；模型不可改写证据，也不会直接连接目标网站。

如果规则检查已经成功、但 AI 解读因为超时、服务商错误或输出格式不合格而降级，结果页会提供 **只重新生成 AI 解读**。该操作只复用已保存的脱敏检查项和规则分数，不会再次请求目标网站，也不会重复创建 Finding 或 Evidence。

## 网址怎么填

- 内置安全靶场：点击页面里的 **使用内置靶场**。
- 网站运行在 Windows 宿主机：通常填写 `http://host.docker.internal:端口`。
- 网站有自己的域名：填写 `https://你的域名`。
- 如果 HTTP 地址会跳转到 HTTPS，请直接填写最终的 HTTPS 地址。

网址必须使用 HTTP 或 HTTPS，不能包含用户名、密码、查询参数或片段。每次体检都必须确认目标归你所有或已获得明确授权；平台只建立该 scheme、host、有效端口和精确路径的临时授权，不把 `/api` 当成 `/api/private` 的前缀授权。体检默认不跟随重定向，DNS 会在请求前后复核；平台中的其他受控请求若允许重定向，也必须逐跳重新通过 Scope Guard。

## 它会做什么、不会做什么

会做：

- 单次、只读、限制响应大小的网站请求
- HTTPS、HSTS、CSP、点击劫持、MIME 嗅探、Referrer Policy 和 Permissions Policy 检查
- Cookie 的 Secure、HttpOnly 和 SameSite 属性统计（不保存名称和值）
- 明文密码表单、跨来源表单、HTTPS 混合内容和服务版本暴露提示
- 保存脱敏证据、生成 Finding，并输出 HTML、Markdown 和 JSON 报告
- 使用真实模型解释结果，并显示模型是否确实调用成功、延迟和 Token 用量

不会做：

- 爆破目录、密码或接口
- 提交表单、尝试登录或修改数据
- 生成或执行攻击载荷
- 自动利用漏洞、获得 Shell 或绕过权限
- 扫描未确认授权的其他域名、IP 或重定向目标

这是一项安全的第一轮体检，不是“没有发现就代表绝对安全”的证明。需要更深检查时，应在书面授权和隔离环境中使用人工代码审计或专门的安全测试流程。

## 对应 API

- `POST /api/v1/website-scans`：执行一次规则体检；`project_id` 可省略，`authorization_confirmed` 必须为 `true`，`safety_level` 只能为 `safe_read_only`。
- `GET /api/v1/website-scans`、`GET /api/v1/website-scans/{scan_id}`：读取历史与单次结果；读取时会把超过恢复窗口仍为 `running` 的遗留记录安全收敛为失败。
- `POST /api/v1/website-scans/{scan_id}/ai-analysis`：只重新生成可选 AI 解读；规则体检必须已经完成，且不会重新请求目标。

请求与响应字段以运行实例的 <http://127.0.0.1:8000/docs> 为准。
